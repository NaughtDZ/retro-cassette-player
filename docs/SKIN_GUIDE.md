# 皮肤制作指南（v1.1.0）

一个皮肤包就是 `skins/` 下的一个目录。启动后从右键菜单 **皮肤** 里切换，也可以改
`config/settings.json` 的 `skin` 字段。

**v1.1.0 起，程序里画出来的每一个图形都可以放进皮肤包**——不再只有磁带和底座。
按钮、旋钮、VU 表、贴纸、进度条、计数器、磁带卷、console 面板、播放列表纸张，
全部都有对应的资源键。没放的部件照样工作（回退成程序矢量绘制）。

| 皮肤 | 特点 | 建议用途 |
| --- | --- | --- |
| `default` | 全套 44 个资源；蓝色梯形底座 + 黄色键帽 + 藏青磁带壳 | 改配色的起点，也是所有资源键的参考实现 |
| `yellow90` | 只覆盖"外观主体"21 张（金色底座/按钮/旋钮/VU + 黄黑外壳）；console 故意置空以回退成金色程序绘制 | 学"只覆盖一部分"的写法 |

> 快速看效果：`tools/make_screenshots.py` 会把整机渲染到 `docs/images/`；
> 改一张图重启程序也能立刻看到（资源按尺寸光栅化后缓存，改文件需重启）。

---

## 1. 最小皮肤

```
skins/mine/
  skin.json          # 必需
  base.svg           # 只放你想换的那些资源
```

`skin.json`：

```json
{
  "name": "mine",
  "description": "我的皮肤",
  "base_pack": "default",
  "colors": { "base": "#7a3f8f", "btn_bg": "#e8d24f" },
  "assets": { "base": "base.svg" }
}
```

`base_pack` 让它继承 `default` 的全部资源与颜色，你只覆盖想改的。**没有 `base_pack`
也可以**——那样所有缺失资源都回退成程序绘制，从零设计也行。

---

## 2. `skin.json` 字段

| 字段 | 说明 |
| --- | --- |
| `name` | 皮肤名（显示用） |
| `description` | 一句话说明 |
| `base_pack` | 继承的包名（通常是 `default`）；可多层继承，最多 3 层 |
| `colors` | 程序绘制部分的颜色（见 §6） |
| `layout` | 各部件的位置尺寸（见 §7） |
| `assets` | 资源键 → 文件名，相对本目录 |

**`assets` 写空字符串有特殊含义**：丢掉继承来的那张图，改回程序绘制。

```json
{ "assets": { "vu_dial": "" } }
```

这就是 `yellow90` 让 console 面板自动变成金色调的手法——回退后颜色由 `colors` 决定。

## 4. 资源约定（重要）

资源不只是"一张图贴上去"。按图形性质分五类，约定如下：

### 4.1 静态底图（直接贴）
`base`、`tape_shell`、`console_zone`、`playlist_paper` 等。图会缩放到 `layout` 或控件
的矩形。

### 4.2 状态变体（后缀）
`<键>_hover` / `<键>_down` / `<键>_on` / `<键>_off`。程序优先找带后缀的，找不到退
回基础键，再找不到才程序绘制。

### 4.3 指针类（按角度旋转）
`vu_needle`、`knob_vol_pointer`、`console_knob_pointer`、`console_switch_lever`。

- 图必须**正方形**
- **图中心 = 转轴**
- 图形画成**竖直朝上**（0°）
- 程序按数值**顺时针**旋转

角度公式（供对照，不必自己算）：

| 部件 | 旋转角 |
| --- | --- |
| 音量旋钮 / console 旋钮 | `扫角 × (值 - 0.5)`，扫角 300°（音量）/ 270°（console） |
| VU 指针 | `VU_ARC × (2×位置 - 1)`，`VU_ARC = 46°` |
| 挡位拨杆 | `270 × (挡位序号 / (挡位数-1) - 0.5)` |

### 4.4 单元素叠加（程序按位置多次贴）
`knob_vol_lit`、`console_knob_lit`、`console_switch_dot`、`console_switch_dot_on`。

这类图只画**一个**元素，程序在"该亮"的每个位置把它贴一次。于是像"刻度随音量逐道
亮起"这种**动态效果也能换皮**，而不是被压成一张静态图。

- 刻度类：正方形，中心 = 旋钮圆心，画在正上方
- 挡位灯类：小方形，中心 = 灯的位置

### 4.5 缩放 / 裁剪类（图 = 极限状态）
| 键 | 约定 | 程序做什么 |
| --- | --- | --- |
| `reel_coil` | 画**满卷** | 按当前半径整体缩放（内圈会被卷芯盖住） |
| `prog_fill` | 画**满值** | 从左按比例露出 |

## 5. 什么该放资源，什么留程序

这条界线比"能不能做"更重要：

**放资源**：形状与环境——底座、外壳、键帽、表盘、凹槽、纸张、指示灯的**外观**。

**留程序**：
- **由数据决定的文本与数值**：标题、时间数字、`RT-90`/`HiFi`、旋钮读数、行号、曲目名。
  做成资源就得引入字模图集，收益为零。
- **条数随内容变化的线**：播放列表的横格线、分栏线、页边线、外框。拉伸一张带边框的
  图会把边框拉粗。
- **连续变换的叠加**：指针角度、卷径、进度填充——这类**形状可以换**（见 §4.3/4.5），
  但数值始终由程序给。

一句话：**资源给形状，程序给数值。**

## 7. `layout`（位置与尺寸）

单位是**真实窗口坐标**，`base` 在 `(76,468)`、尺寸 `808×132`。

| --- | --- | --- |
| `tape` | `(220, 96, 520, 356)` | 磁带整体 |
| `base` | `(76, 468, 808, 132)` | 底座 |

## 8. SVG 还是 PNG

两种都支持，按扩展名识别。

- **SVG**：推荐。任意缩放不糊，改一行颜色就能看到效果。
- **PNG**：也能用，但会被缩放（保持长宽比、平滑插值）。

> v1.1.0 修掉了一个老问题：PNG 资源此前**静默失效**（`QPixmap.scaled` 收到整数枚举会抛
> `TypeError`，而调用被包在 try 里，于是悄悄回退成程序绘制）。现在 PNG 可用了。

## 9. 调试技巧

| 想做的事 | 怎么做 |
| --- | --- |
| 只改一个部件看效果 | 把 `assets` 里那一项改成 `""` → 该部件立刻回退程序绘制，方便对照 |
| 确认某张图有没有被读 | 启动日志会打印 `[skin] 资源缺失：...` / `[skin] 资源加载失败 ...` |
| 确认指针角度对不对 | 用 `tools/make_screenshots.py` 渲染，或截图后量指针相对竖直方向的夹角 |
| 换肤立刻生效？ | 主界面/console/播放列表都会跟着换；**改了图片文件本身需要重启**（有光栅缓存） |

## 10. 范例：yellow90 是怎么做的

`yellow90` 要一套金色外观，但形状必须和 `default` 一模一样。**手抄 20 张图迟早会把某个
坐标改错**，所以它用色板映射从 default 的 SVG 自动生成：

```python
PALETTE = {
    "#2a6485": "#c9a52c",   # 底座蓝 -> 金
    "#3f7ea3": "#d8b545",   # 窗口键藏青 -> 浅金
    "#ccd7de": "#e6dcb8",   # 旋钮高光 -> 暖白
    # ...
}
# 正则替换所有 #rrggbb 后写出，形状部分逐字节继承
```

只保留三个颜色不映射：`#000000`（黑）、`#ffffff`（高光）、`#cf4a3c`（VU 红区弧）。

**console 的处理更省事**：干脆不给资源（`"console_zone": ""` 等 12 个键置空），让它回退
成程序绘制——程序绘制的颜色来自 `colors`，于是 console 自动变成金色调，**一张图都不用出**。

这就是"只覆盖外观主体"的最优写法：能靠 `colors` 自动跟随的部分就不出图。
